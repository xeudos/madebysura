# Interval — Made by Sura

Native SwiftUI interval timer. Version 1.2.4 removes Live Activities, the widget extension, Dynamic Island support, local notifications, their settings and diagnostics.

Includes favorites, dark/light/system appearance, interval audio and countdown beeps, optional three-second skip preparation and immediate second-tap skipping. Pause and Skip stay pinned on screen. Audio mixes with music and supports screen locking. No timer history.

Build with XcodeGen using project.yml. GitHub Actions builds the unsigned arm64 IPA, runs unit/UI tests, verifies no widget extension or Live Activity flag is present, and inspects the IPA with REA.
